# Antibody Motif Explorer
Research-use sequence screening. DRAC is an illustrative amino-acid query, not a validated engineering mechanism.
Open index.html locally or enable GitHub Pages from main / root.
Download the therapeutic antibody CSV from [Thera-SAbDab](https://opig.stats.ox.ac.uk/webapps/sabdab-sabpred/therasabdab/search/) and import it. All processing is local. No credentials required.
Scores represent sequence identity only, not conjugation feasibility, clinical value or licensing probability. Coordinates are 1-based positions in supplied sequences, not IMGT numbering. Structural compatibility and commercial ownership require independent verification.
